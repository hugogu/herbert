Herbot Bot 是一款编程解谜游戏，核心只有一个想法：用更少的代码，表达更多的思路。

在 25 × 25 的棋盘上，引导小机器人点亮所有目标。你用 H 语言描述路线，它只有三个指令：s 前进一步，l 左转，r 右转。每个字母和数字都计 1 byte，所以每一关不仅要求程序正确，还要足够简短。

边玩边学
• 50 道原创关卡、十个章节，从迈出一步到构建递归系统
• 逐步掌握过程、参数、以指令作为参数，以及递归
• 每关都有清晰的目标和两条可选提示，绝不直接给出答案
• 内置玩法手册，配合示例讲解整门语言

看见思路运行
• 运行、暂停或单步执行程序，跟随机器人留下的轨迹
• 1×、4×、16× 与极速四档速度
• 墙会挡住机器人；踩到陷阱会清空已点亮的全部目标
• 现代与经典两种棋盘风格，可选网格点和移动轨迹
• iPhone 和 iPad 上可双指缩放、拖动棋盘；Mac 上按 ⌘Return 运行

每个字节都算数
• 自动保存每一关的最短解
• 草稿随写随存，回来时自动恢复
• 导出、导入 JSON 备份，在设备之间迁移进度

AI BATTLEFIELD（可选）
想知道 AI 模型如何解这些谜题？添加你已在使用的服务商（OpenRouter、硅基流动 SiliconFlow、Google Gemini，或任何兼容 OpenAI、Anthropic 接口的服务），填入你自己的 API Key，选择模型和题目即可开赛。每个提交的程序都在本机判分，并记录重试、用时与 Token 用量，还能生成可分享的成绩图。只有在你保存服务商或同意开始比赛时，应用才会用你的密钥直接向该服务商发送请求；密钥保存在系统钥匙串中。AI Battlefield 需要你自己的服务商账号，服务商可能就此收费；不使用它也能完整体验游戏。

离线与隐私
无需账号，没有广告、追踪或 App 内购买。关卡、进度和设置都保存在你的设备上。支持英语、简体中文和日语。

Herbot Bot 依据 Herbert 编程挑战的公开规则独立实现。Herbert 挑战由 Wild Noodle Corporation 创作，H 语言由其创始人 Brian Conte 开发。本应用与 Wild Noodle 或 Microsoft 无关联。应用中的全部关卡均为原创设计，源代码在 GitHub 上开源。
