2. PURPOSE AND AUDIENCE
Herbot Bot is an educational programming puzzle game for anyone learning to program, from older children and students to teachers and professional developers. Players guide a robot to light every target on a 25 x 25 board by writing very short programs in H, a language with three commands: s (forward), l (turn left) and r (turn right). Fifty original puzzles in ten chapters introduce sequencing, procedures, parameters and recursion, ideas that many learners find hard to grasp from text alone. Every puzzle has a goal and two optional hints, programs run step by step with immediate visual feedback, and the game rewards the shortest correct program. It works fully offline, without an account, ads, tracking or purchases.

3. HOW TO USE THE MAIN FEATURES
No login, setup or sample files are required.
- Problems: tap "Take the first step" to open L01, type s (or tap the s key) and tap Run; the puzzle is solved. L02 is solved by: rsslsslss. Each puzzle shows its goal above the board; "Show the next hint" reveals a hint, and "Rules" explains H.
- Guide: the second tab explains the language with examples.
- My > Progress: lists solved puzzles; Export and Import save and restore a JSON backup.
- AI Battlefield (optional): open AI Providers ("Models" on iPhone) > Add provider, choose its type, enter the HTTPS base URL and an API key, and save to load models. Under New match ("New" on iPhone), choose models and puzzles, then tap "Agree & start match".

4. EXTERNAL SERVICES
The puzzle game uses no external service. Only the optional AI Battlefield contacts an AI service: the provider the user configures with their own API key, such as OpenRouter, SiliconFlow, Google Gemini, OpenAI or another OpenAI- or Anthropic-compatible HTTPS API. Requests go directly from the device, only when the user saves a provider (to list models) or agrees to start a match (rules, puzzle boards, an optional prompt and the AI conversation). The app contains no API keys; keys stay in the Keychain. The developer does not proxy AI requests or operate an analytics or payment service. The optional leaderboard uses the configured Worker service and Apple authentication. Model answers are judged by the app's own interpreter: H programs only move the robot and are never executed as native code.

5. REGIONAL DIFFERENCES
None. Features and content are the same in every region; only the interface language follows the device (English, Simplified Chinese or Japanese).

7. OPTIONAL LEADERBOARD (2.0.0)
When a service URL is configured, My > Account provides Sign in with Apple, nickname editing and account deletion. Puzzle pages offer explicit solution uploads; the server replays programs to verify scores. Only nicknames and verified scores/metrics are public, not solution programs. Offline play still needs no account.
