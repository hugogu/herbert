# 原版规则核对

来源：http://herbert.tealang.info/rule.php ，2026-10-07 读取。原始响应 SHA-256：`6fa113d0f633e2828e462fd31b69789e4b0121c2b4030b1276af517c2030a7d5`。

本项目独立实现规则，不再分发原站页面、图片或 Flash 文件。以下为事实性核对说明。

- 机器人只能执行代码，不能直接通过方向按钮移动。
- s 前进一格，l/r 原地旋转 90 度；墙和棋盘边界阻挡移动，指令仍消耗一步。
- 25×25 棋盘；目标全部点亮时立即完成，陷阱清空之前点亮的全部目标。
- 程序先声明过程，最后恰有一个执行行。过程名为小写单字母，参数名为大写单字母。
- 命令参数可递归拼接，可为空；数值参数支持加减，绝对值至多 255；任一数值参数非正时跳过整次过程调用。
- 每个字母计 1 byte；连续数字组成一个数值常量，计 1 byte；其他语法标点与空白不计。
- 每关有独立长度限制，只有长度符合限制且点亮全部目标时算完成；步数不参与最短代码记录比较。
- 原站声明最多 100 万执行步与 100 万 byte 展开长度。原生引擎另有避免阻塞 UI 的保护上限，具体差异在 README 记录。

原站公布的是日文规则，且声明其实现与最初的 Herbert 存在差异。本项目优先依据这一页面及其公开关卡接口，不以其他复刻版本代替原版规则。
