# 50 道原创学习关卡

这套课程依据公开的 H 语言与棋盘规则独立设计，没有把社区棋盘改名或改图后使用。原创布局、名称、学习目标、提示、生成脚本与参考程序随项目以 MIT 许可发布。

入门两章共十题：仅前两题可直接逐步写出路线，随后学习复用、递归、指令参数和组合。后八章共四十道进阶、大师与综合题：墙辅助计数、状态与折返、嵌套图案、递归系统、分形图案、变换与逆程。L04–L06 与 L10–L50 用断续墙段、折角与陷阱带组织开放空间，各类障碍用量分别为完整路线边界的 15–30%；L11–L22 重做几何形态，L23–L30 保留原有目标构图，L31–L40 延展闭合环与分枝。L41–L50 在保持前四十题不变的基础上，增加双尺寸交换、成对指令增长、装饰曲线的逆程及多层递归组合。每章先用小图形介绍新概念，再迁移到复杂图案。全部关卡开放，不锁进度。每题先显示目标，两条提示由玩家逐条展开。其他有效解同样被接受。

byte 上限是经过引擎验证可达的练习预算，不声称是最优解长度，也不按数值大小代表难度。计分题的参考程序只在测试资源中，不进安装包；AI 提示词的公开教学示例使用独立棋盘。

显示编号连续为 L01–L50。L41–L50 使用全新内部 ID 10108–10117；L01–L40 的棋盘、预算和存档含义保持不变。此前改版的 L04–L06 使用 10074–10076，L10–L30 为 10077–10097，大师关卡 L31–L40 为 10098–10107，上一轮 ID 退役。旧记录可导入但不会误算为新关卡的通关；历史比赛保留原棋盘快照。
