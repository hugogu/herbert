# 30 道原创学习关卡

这套课程依据公开的 H 语言与棋盘规则独立设计，没有把社区棋盘改名或改图后使用。原创布局、名称、学习目标、提示、生成脚本与参考程序随项目以 MIT 许可发布。

入门两章共十题：仅前两题可直接逐步写出路线，随后学习复用、递归、指令参数和组合。后四章保留二十道进阶题：墙辅助计数、状态与折返、嵌套图案和递归系统。每道进阶题都有参与路径约束的墙，逐步引入参数交换、递归返回、互递归、镜像与多层组合。每章先用小图形介绍新概念，再迁移到复杂图案。全部关卡开放，不锁进度。每题先显示目标，两条提示由玩家逐条展开。其他有效解同样被接受。

byte 上限是经过引擎验证可达的练习预算，不声称是最优解长度，也不按数值大小代表难度。计分题的参考程序只在测试资源中，不进安装包；AI 提示词的公开教学示例使用独立棋盘。

v0.3.3 使用连续的 L01–L30。L07/L08 为重新设计的「旋转玫瑰」和「双灯相映」；其余棋盘保留。显示编号与内部存档 ID 分开，退役题记录与历史比赛快照继续保留。
