# 开放几何关卡改版

本次重点重构 L11–L22。L10 保留目标，打开围墙；L23–L30 保留目标位置和机器人起点、朝向，只调整墙和陷阱。L04–L06 新增「晴光庭院」「菱形阶梯」「生长螺旋」，保留数值计步、通用重复器、指令增长的递进顺序。L01–L03、L07–L09 不变。本轮设计已确认，README 中英文截图沿用原来的选题并重新截取。

## 设计原则

旧生成器沿参考路线铺设边墙，容易把题目变成一条指定走廊。现在将目标构图、参考走法和障碍布置分开：目标表达几何规律，局部墙面提供停靠点或标出图形层次，陷阱约束越界、横穿和折返位置，其余空间留给玩家安排路线。

墙会挡住前进一步，但后续指令继续执行；陷阱可以进入，会熄灭全部已点亮目标，机器人位置和朝向继续保留。两者承担不同的推理任务。陷阱放在图案附近的负空间，不能只散落在无关的棋盘角落。

借鉴社区 0006–0016 的层次、稀疏目标、对角周期、局部口袋与旋转组件；没有复制、旋转或拼接社区棋盘。不是每关都要求某种特定语法，也不声称参考答案最短。

## 验证及边界

- 真实 H 引擎重放全部 30 个参考程序，与独立的几何指令 oracle 核对 byte、指令数、终点、朝向、撞墙和陷阱次数。
- L04/L05 与 L10–L23 共 16 关验证至少两条预算内、不同运动次序的安全解；这并不表示每关都存在两种完全不同的算法。
- L04–L06、L10–L30 的墙和陷阱数量，分别为完整路线边界格数的 15–30%。分母是参考几何路线及其起始旋转形成的安全格集合之外、与之正交相邻的格数，按实际棋盘去重，不按 625 格总面积计算；墙和陷阱不要求全部贴边，而是按折角、短带、珠点与负空间构图独立布置。两类障碍都至少有一处紧邻目标。在目标包围盒外扩一格的区域中，全部目标可安全连通，至少 60% 的目标有三个以上安全邻格，并存在多个安全环路。空间开放指标不能单独证明程序难度或最优解。
- L23–L30 的目标与起点几何哈希锁定改版前数据；这些关卡的参考程序保持原样。
- 显示编号仍为 L01–L30；L04–L06 的新内部存档 ID 为 10074–10076，L10–L30 为 10077–10097，上一轮 ID 也退役。旧记录可导入但不会误算为新关卡的通关；历史比赛继续使用自己的棋盘快照。
- 参考程序和替代程序只在测试资源中，应用资源不包含答案。
