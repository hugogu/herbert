# HOJ 规则与实现核对

2026-10-08 对照 [quolc/hoj 的固定提交 f5d1ee4](https://github.com/quolc/hoj/tree/f5d1ee4e3616c1b2cf79e70a0ccee267b5f09ea3)
和[原站规则页](http://herbert.tealang.info/rule.php)。该仓库自称 HOJ 代码片段，包含 Ruby 解释器和示例判题器；没有 Flash UI、排行榜服务或完整的微软原作。
本项目没有复制其中的源码或素材。

| 检查项 | 结论 |
| --- | --- |
| 棋盘编码 | 修正本项目之前读反的符号：`x` 是墙，`*` 是陷阱。社区原始 JSON 不变；原创课程同步调整编码，布局与参考解不变。 |
| 撞墙 / 边界 | 机器人原地停留，仍消耗一条指令，接着执行下一条；不会结束程序，也不会产生运动轨迹。 |
| 分支 | H 没有撞墙传感器或 `if`；任意数值参数非正，跳过整次过程调用并返回调用者。有效数值范围内的行为一致。 |
| 陷阱与回访 | 踩陷阱清空所有目标状态，机器人停在陷阱上；可以重新点亮目标，同一亮着的目标不会重复计数。 |
| 通关 | 最后一个目标亮起时立即成功，不执行后面的陷阱路径或无限递归。 |
| 字节与成绩 | 字母逐个计数，连续数字算一个数值，语法标点免费；按 byte 数比较最短解，步数不计分。原站同分按提交时间排序，本机没有在线排行榜。 |
| 长度限制 | 原站规则要求代码不超过本关上限。Ruby 示例读取了上限但没用于判定；本项目在运行前检查。不能据此推断完整线上服务漏检。 |
| 指令参数与递归 | 17 组独立编写的差分用例在两端给出相同指令序列与 byte 数；当前 30 道原创题（含 0.3.3 重做的 L07/L08）和 8 个社区试解均在原预算内通过参考判题器；社区第 1 题的撞墙继续执行用例同样通过（仅此撞墙测试放宽 byte 预算，原题上限不变）。 |
| 连贯墙体 | 相邻墙格合并绘制外轮廓；Classic 黑色直角，Modern 圆角，保留围墙内的洞，对角相邻不额外连桥。参考仓库没有 UI 绘制代码可供比对。 |

## 建议保留的改进

- **接受空白和常见换行格式，空白不计 byte。** Ruby 原始计数器会把空格和 CR 算入，解析器也拒绝它们；手机输入、粘贴和排版不应影响有效程序长度。
- **继续严格限制 ±255。** 规则禁止超范围数值，Ruby 片段却允许 `256`；本项目对常量和求值结果均检查。
- **保留可取消的惰性执行与资源保护。** 原版直接展开字符串，存在内存膨胀风险；本项目使用有界展开、尾递归与分批执行。展开计数、内存权重和额外嵌套限制与 Ruby 不完全相同，不承诺极端程序的超时边界一致。
- **保留 byte 排名，不增加撞墙或步数惩罚。** 简短的程序可能故意撞墙、重复转向；增加运动效率评分会改变谜题目标。

另有明确的语法/诊断差异：本机支持 `a(-1)`，Ruby 需写成 `a(0-1)`；本机在参数实际使用时检查类型，Ruby 的静态推断会拒绝某些未使用参数；本机先求出全部参数再判断跳过，可能报告后续参数的越界错误。
这些差异、资源阈值和复现方法详见 [完整英文审计](hoj-compatibility.md)。

## 旧存档

草稿和历史记录原样保留，不自动删除旧成绩。以前在错误的墙/陷阱解释下保存的社区题解，需要重新运行确认。
导入备份时会用修正后的引擎重放完成记录，未通过的备份不会覆盖本机数据。
