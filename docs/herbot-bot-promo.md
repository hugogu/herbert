# Herbot Bot feature film

English promotional media for the macOS 0.4.0 app, using real native captures of the App Store target and its 30 original lessons.

## Deliverables

Output directory: `outputs/app-store-macos/0.4.0/promo-en/` (ignored by Git).

- `herbot-bot-feature-film-45s.mp4`: full feature film, 20 shots in seven chapters.
- `herbot-bot-preview-30s.mp4`: a separately narrated 30-second cut for the Mac App Preview slot.
- `voiceover-45s.wav` / `voiceover-30s.wav`: isolated English narration.
- `captions-45s.srt` / `captions-30s.srt`: English captions, also burned into the videos.
- Matching JPEG posters, format reports and a visual review contact sheet.

Both cuts use 1920 × 1080 progressive H.264 High Level 4.0 at 30 fps, stereo AAC at 48 kHz, and fast-start MP4 packaging. Encoder target: 10 Mbps video / 256 kbps audio; actual variable bitrate is recorded in the reports. The 45-second film is for a website or social promotion; use the 30-second cut for App Store Connect. Apple review still determines acceptance.

## Story and pacing

| Full film | Chapter | Feature |
| --- | --- | --- |
| 0–4 s | Hook | Three commands, 30 puzzles, one robot |
| 4–10 s | Code | H editor, real execution, byte limit |
| 10–16 s | Debug | Run/pause controls and native single stepping |
| 16–23 s | Grow | Course progression, parameters and recursion, L30 |
| 23–29 s | Explore | Modern/Classic boards and offline progress |
| 29–38 s | AI Battlefield | Choose entrants, equal puzzles/rules, native judging |
| 38–45 s | Identity | Completed pattern and product closing card |

Cuts land on the half-second grid of an original 120 BPM electronic pulse bed. Large feature titles, close-ups and short recorded sequences replace the earlier long continuous run. Source execution is played at its recorded speed; the app itself was set to 4× during the rose recording. The Mosaic fragment illustrates stepping and is not a full solution.

AI screens show actual configuration interfaces. No requests were started, no API keys are shown, and no model performance scores are invented. On-screen copy identifies the optional AI feature, API-key requirement and possible provider charges. Provider/model names reflect the configured capture environment; availability depends on the user's provider.

## Voice and sound

- Engine: cached **Kokoro-82M v1.0**, `kokoro-onnx`.
- English voice: `af_heart`, speed 1.08; seven separately synthesized chapters per cut.
- Narration timing is retained in `audio/voice-report.json` and `short-audio/voice-report.json`.
- AI is submitted to the English front end as `AI`, which produces the letter names. `A I` incorrectly treats the first letter as an article.
- An original synthesized percussion/arpeggio bed is generated by `synthesize.py`; it uses no sampled recordings or external music.
- Music ducks under speech. The final mix targets −16 LUFS integrated and a −1.5 dBTP ceiling. Check the encoded result, not only the input WAV.
- Kokoro model weights: Apache-2.0; kokoro-onnx: MIT. See the model distributors' license files if redistributing weights or runtime. Models are not included in the media package.

## Reproduce

Read `scripts/promo/storyboard.json` and `storyboard-short.json` for the exact narration. Provide a local model directory containing `kokoro-v1.0.onnx` and `voices-v1.0.bin`; synthesis does not download anything.

```sh
python scripts/promo/synthesize.py --models "$KOKORO_MODELS" --output outputs/app-store-macos/0.4.0/promo-en/audio
python scripts/promo/synthesize.py --models "$KOKORO_MODELS" --story scripts/promo/storyboard-short.json --output outputs/app-store-macos/0.4.0/promo-en/short-audio
python scripts/promo/render.py --output outputs/app-store-macos/0.4.0/promo-en
python scripts/promo/render.py --output outputs/app-store-macos/0.4.0/promo-en --short
```

Synthesis needs numpy, soundfile and kokoro-onnx. Rendering needs Pillow, the standard macOS Avenir Next/Menlo fonts, ffmpeg and ffprobe. The original capture workflow is in `app-store-macos-media.md`. Extra source screenshots in `promo-en/sources/` were captured from the native app with desktop automation: AI setup, model selection, progress, guide, and the scrolled recursion examples. Preserve these inputs to reproduce this cut. Do not replace them with fictional app interfaces.

Review exported frames from every shot, decode both complete movies, verify audio loudness and format reports, and check narration against the scripts. A recognizer can catch omissions and obvious pronunciation issues but does not replace a final listening review. No Apple upload or release submission is performed by these scripts.
